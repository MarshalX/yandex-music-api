# 📻 Консольное радио «Моя волна»

Интерактивный пример на [сессиях радио](radio.md): выбираете волну (Моя волна или занятие) и её характер, после чего треки играют один за другим. Радио получает обратную связь о прослушиваниях и пропусках и подбирает следующие треки с их учётом.

Управление во время воспроизведения: `Enter` — следующий трек, `l` — нравится, `d` — не нравится (и дальше), `q` — выход.

Треки воспроизводятся установленным в системе плеером (`afplay`, `mpv`, `ffplay` или `cvlc`), свой плеер можно указать в переменной окружения `PLAYER`. Сторонние Python-библиотеки не нужны.

Запуск:
``` bash
TOKEN=<ваш токен> python wave_radio.py
```
