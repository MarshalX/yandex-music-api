# Maple Music

Нативный клиент для iOS 17+ на SwiftUI с интерфейсом по мотивам Apple Music.
Иконка взята из `base/icon-change/icon.png`, используются системные шрифты и SF Symbols.
В приложении нет рекламных или аналитических SDK.

## Реализовано в исходниках

- Прямое подключение к неофициальному API Яндекс Музыки: поиск треков, «Моя волна»,
  избранное, список и содержимое плейлистов, создание плейлистов, добавление/удаление треков.
- Вход по коду устройства через страницу Яндекса; альтернативно — проверка и сохранение
  пользовательского Music OAuth-токена в Keychain. Пароли в клиент не вводятся.
- Переключение провайдера и адреса API в Settings: Yandex Music, Custom API Gateway, Local Demo.
  Токены привязаны к конкретному провайдеру и адресу, между адресами не переносятся.
- Два режима Playback API: `File info` для lossless/encraw и `Download info` для совместимого MP3.
  Переключение ручное: ошибки авторизации не запускают запросы к другим серверам.
- `AVPlayer`, очередь, shuffle/repeat, перемотка, фоновое аудио, команды экрана блокировки, AirPlay.
- Запрос FLAC и отображение реально возвращённого кодека. Если сервер не выдаёт lossless,
  запрос завершается понятной ошибкой, без подмены качества подписью LOSSLESS.
- Текст LRC с синхронизацией и переходом по строкам, поддержкой повторных временных тегов и offset.
- Загрузки с метаданными и лирикой, отдельные каталоги для каждого провайдера/аккаунта,
  восстановление офлайн-библиотеки после перезапуска, исключение аудио из резервного копирования.
- `encraw`: AES-CTR с ключом, полученным в авторизованном ответе API. Локальные аудиофайлы
  защищены iOS Data Protection (`completeUntilFirstUserAuthentication`). Ключи транспорта в manifest не пишутся.
- Локальный демо-каталог с четырьмя оригинальными PCM-файлами по 18 секунд.

## Ограничения текущей версии

Это пока не проверенная замена всех возможностей оригинала. Реальные запросы поиска,
полного воспроизведения, lossless, входа и плейлистов нужно проверить на аккаунте пользователя.
API неофициальный и может измениться. Доступность треков и качества определяет сервер.

Для первого воспроизведения `encraw` текущая реализация полностью загружает файл перед стартом.
Прогрессивное воспроизведение зашифрованного потока, HLS-offline/FairPlay, возобновление фоновых
загрузок после завершения процесса, gapless, CarPlay, подкасты, видеоклипы и отдельные страницы
альбомов/артистов ещё не реализованы. Поиск пока возвращает первую страницу треков.
«Моя волна» загружает одну выдачу; автоматическое продление радиосессии не реализовано.
Выбор качества применяется к следующему запуску трека; сохранённая офлайн-копия имеет приоритет.
Плейлисты в демо-режиме пока сохраняются только в памяти.

Это собственный офлайн-кэш; импорт зашифрованной базы/лицензий оригинального приложения отсутствует.

## Запуск

1. Открыть Settings через кнопку аккаунта.
2. Выбрать провайдер и Playback API, нажать Apply Provider.
3. Для Yandex Music нажать Sign in with Yandex, открыть ссылку и подтвердить код.
   Если device flow не принимается сервером, использовать токен своего музыкального аккаунта.
4. Для другого сервера ввести его HTTPS-адрес и отдельный токен этого сервера.
   Контракт описан в [docs/backend-api.md](docs/backend-api.md).
5. Для автономного ознакомления выбрать Local Demo.

## Сборка IPA без macOS на своём компьютере

Нужен **собственный GitHub-репозиторий** с этим SwiftUI-проектом и доступными Actions.
`MarshalX/yandex-music-api` — сторонняя Python-библиотека, она используется как справочник,
а не как репозиторий для сборки Maple Music.

В Actions запустить **Build unsigned IPA**. Workflow использует `macos-15`, Xcode 16.4,
XcodeGen 2.46.0 с проверкой SHA-256; запускает XCTest на iOS 18.5, архивирует arm64-приложение
и публикует `MapleMusic-unsigned.ipa`. Диагностика тестов сохраняется отдельным артефактом.
IPA нужно подписать своим аккаунтом через Sideloadly/AltStore перед установкой.
Сертификаты Apple и пользовательские музыкальные токены не нужны в CI.

`Package.swift` и `xtool.yml` также подготовлены для [xtool](https://github.com/xtool-org/xtool).
На Windows этот вариант требует WSL, Linux Swift и iOS SDK из Xcode.xip. На текущей машине
WSL/Apple SDK не настроены. Локальный Mac для GitHub Actions не требуется.

## Проверки на Windows

```powershell
python -m pip install --target work/validation-pydeps tree-sitter tree-sitter-swift pyyaml
python tools/validate_source.py
python tools/package_source.py
```

Статическая проверка разбирает Swift-синтаксис, YAML/plist/JSON и demo WAV.
Она **не заменяет Swift type checking, XCTest, симулятор и сборку IPA**.
Текущее состояние проверок и источники протокола: [docs/verification.md](docs/verification.md).
